## My understanding of SAP so far

- SAP is an **ERP (Enterprise Resource Planning)** system used by 9 out of 10 Fortune 500 companies
- It connects business modules — FI (Finance), MM (Materials), SD (Sales), HR, and the Technology workstream (ABAP, Fiori, BASIS, CPI, BODS)
- **ABAP** is the programming language that runs on the SAP Application Server and is used to build reports, automate workflows, and customise SAP behaviour
- SAP follows a **3-tier architecture**: Presentation Layer → Application Server → Database
- The **ABAP Data Dictionary** (SE11) is where all table definitions, structures, and data elements live
